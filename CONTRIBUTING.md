# Contributing Guide

Thanks for helping make this the most useful n8n workflow pack on GitHub! 🎉

## Ways to Contribute
- **Submit a workflow** (new or improved)
- **Fix documentation** or add usage notes
- **Report bugs** or request new workflows

## Workflow Submission Checklist
Before opening a PR:
- [ ] Export the workflow JSON from n8n
- [ ] Remove any secrets, tokens, or personal data
- [ ] Use clear naming (no “final_final.json”)
- [ ] Add a short description in your PR
- [ ] Mention required credentials and setup steps

## File Placement
- Place single workflows at the repo root when they are standalone
- Group related workflows in a dedicated folder
- If the workflow is part of a multi‑workflow system, include a short README in that folder

## Pull Request Steps
1. Fork the repo
2. Create a feature branch
3. Add your workflow or docs
4. Open a PR and describe:
   - What the workflow does
   - Trigger type (webhook, schedule, manual)
   - Required credentials

## Code of Conduct
By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

Questions? Open an issue and we’ll help you get started.
